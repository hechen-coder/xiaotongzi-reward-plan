# Personal Reward Plan System (个人奖励计划系统)

这是一款轻量级的个人日常奖励与打卡系统。通过设定积极任务（加分项）、持续性任务（如学习时长）、消极任务（扣分项），你可以将日常生活游戏化。积累的积分可以用于在“商城”中兑换各种设定的奖励（如奶茶、外卖等）。

> **说明**：当前代码库中界面可能包含专属称呼（如“小彤子”），这属于个人定制化称呼，你可以在前端代码中自行搜索并替换为你或你伴侣的专属名称。

## ✨ 核心特性

- **数据多端同步**：通过本地 Node.js 后端服务，数据实时保存在服务器中（摒弃了单机 `localStorage`），实现手机、电脑多端数据同步。
- **正负激励机制**：灵活配置加分与扣分项。
- **成就与兑换商城**：利用积分兑换目标奖励，以及累计积分达成里程碑成就。
- **本地化隐私**：数据完全存储在你自己的电脑（`server_data.json`）上，安全可靠。

## 🚀 部署指南 (基于 Cpolar 内网穿透)

本系统采用 `Node.js (Express) + 纯前端 (HTML/CSS/JS)` 架构。你可以将个人电脑作为服务器进行部署，并通过 [Cpolar](https://www.cpolar.com/) 暴露给外网，以便在手机上随时访问。

### 1. 环境准备
- 确保电脑已安装 [Node.js](https://nodejs.org/) (推荐 v16+)。
- 下载本项目代码到本地。

### 2. 启动本地服务
打开终端（命令行），进入项目根目录：

```bash
# 1. 安装依赖
npm install

# 2. 启动服务器 (默认运行在 3000 端口)
npm start
```
此时，在浏览器中访问 `http://localhost:3000` 即可看到页面。

### 3. 外网访问 (Cpolar 配置)
为了在没有连接家里 WiFi 的情况下（如在外面用手机流量）也能打卡，我们需要进行内网穿透：

1. 前往 [Cpolar 官网](https://www.cpolar.com/) 注册账号并下载安装客户端。
2. 登录 Cpolar 后台，获取你的 Authtoken。
3. 在电脑终端中配置 Authtoken（仅首次需要）：
   ```bash
   cpolar authtoken <你的Authtoken>
   ```
4. 将本地的 `3000` 端口映射到公网：
   ```bash
   cpolar http 3000
   ```
5. Cpolar 会在终端输出一个公网 URL（例如 `https://xxxx.cpolar.io`）。
6. **完成！** 现在你可以在手机浏览器中输入这个 URL，随时随地进行打卡和兑换了。

## 🛠️ 自定义配置

如果你想修改任务内容或商城奖品，请直接编辑根目录下的 `app.js` 文件：
- `tasksData`：包含积极任务 (`positive`)、时长任务 (`duration`)、消极任务 (`negative`)。
- `shopData`：包含兑换商城 (`exchange`) 和累计里程碑 (`milestone`)。
